- 画布配色沿用家族 GUI v1.2.0 用户指定样式：**实测谱=蓝色 ×、计算谱=黑色实线、

  主窗口不反向依赖面板内部结构。

## 2. 基本操作流

| 步骤 | 操作 | 结果 |
|---|---|---|
| 1 | 菜单「文件 → 打开谱图…」 | 画布显示原始谱；**自动触发物相判定** |
| 2 | —（判定后台进行） | 状态栏「正在判定物相…」→ 通过则放行精修 |
| 2b | 判定**未通过** | 弹「物相判定结果」对话框说明结构类型，**精修保持禁用** |
| 3 | 右侧选 CIF → 「开始精修」 | 后台线程跑三段管线；状态栏显示迭代进度 |
| 4 | —（精修中） | 「开始精修」禁用，状态栏出现「取消」按钮；窗口可拖动、可交互 |
| 5 | 精修完成 | 画布切换为观测/计算/差值叠加图；右侧结果卡填满 |
| 6 | 工具条「平滑/扣背景/去Kα2/寻峰」 | 仅改**显示谱**，底部峰列表同步 |
| 7 | 工具条「重置」 | 回到原始谱，清掉峰标记 |
| 8 | 菜单「语言」 | 中/英/日**运行时热切换**，界面与结果卡文案即时刷新 |
| 9 | 菜单「文件 → 导出 …」 | 导出 PNG / SVG / CSV / TXT / HTML 报告 |

### 处理语义（重要）

- 每个处理动作都作用在**原始谱**上，是「单步替换」而非链式叠加：
  点了「平滑」就只显示平滑谱，要回到原图点「重置」。
- **喂给精修的永远是原始谱** —— Rietveld 把背景当线性参数一起最小化，
  平滑会破坏残差的统计性质，去 Kα2 会丢掉双线信息
  （`ncm.core.preprocess.for_refinement` 专门存在就是为了让这一点显式）。
- 处理链的物理顺序（去Kα2 → 扣背景 → 平滑）由 `ncm.core.preprocess` 保证；
  判定门内部另有专用链 `ncm.core.peaks.prepare`。

### 精修管线（结果卡里的数从哪来）

```
stage1a  峰形(zero/U/V/W/η/asym/B) + 晶胞 + 择优取向(001)
stage1b  以 1a 的解为初值，放开 TCH 尺寸项 → 晶粒尺寸 D、微观应变 ε
stage2   Li 占位 occ_Li + O 的 6c 参数 z_O（峰形/晶胞冻结）
stage3   由 TCH 的 Y/X 反演晶粒尺寸与微观应变
```

- **为什么要分 stage1a / stage1b**：PO 的择优取向参数 r 与 TCH 的尺寸项 Y
  在部分反射上强相关，一次性同开会落入坏解（实测 Rwp 3.87 %、U 触下界 0）；
  分段后 Rwp 3.16 %、D = 155 nm。详见 `docs/TASKS.md` T6.4d。
- **占位段用缩放后晶胞**：stage1a/b 精修过晶胞（±1 %），第二段必须用
  `structure_scaled`，否则峰位整体错开，Rwp 会从 3 % 劣化到 22 %。
- **晶粒尺寸 = 相干衍射畴尺寸**，不是 SEM 二次颗粒粒径；D 超过 5 μm 记为
  「超出检出上限」。

### 结果卡的读法（口径提示）

| 显示 | 含义 |
|---|---|
| Li 占位 | occ_Li（Li 层 3a 位点占有率，与反位互补） |
| O 的 z | 6c 位点的 z 坐标（层间氧位置，决定 (00l) 强度比） |
| 晶粒尺寸 | 由 TCH 洛伦兹尺寸项 Y 反演（Kλ/D，K = 0.89） |
| 微观应变 | 「未检出可分辨微观应变」表示 ε 触下界（X→0），**不是** 0.000 |
| RB（Bragg） | 扣背景、按计算贡献分配峰强度后的 R 因子 |
| GOF | Rwp / Rexp |
| 空间群 / 晶系 / 点群 / 劳厄群 | 来自 CIF 的空间群符号，查 International Tables Vol.A |

- 「未测定」与「测得 0」**严格区分**：没做/做不出来的项写「未测定」，
  做出来是 0 的项写「未检出可分辨微观应变」。
- 晶系名随界面语言切换：中文界面「三方」，英文/日文界面 `trigonal`。

### 导出（T7.1）

菜单「文件 → 导出 …」提供五种格式，**只有完成精修后才启用**；换谱后重新
禁用（旧结果不能导出）。

| 格式 | 内容 | 说明 |
|---|---|---|
| PNG | Rietveld 标准图（上：实测/计算/背景；下：差值） | 160 dpi，白底 |
| SVG | 同上，矢量 | 矢量出版用 |
| CSV | 逐点：2θ / 实测 / 计算 / 差值 / 背景 | UTF-8 **带 BOM**，Excel 双击不乱码 |
| TXT | 结果卡纯文本 | 口径与邮件摘要完全一致 |
| HTML | 自包含报告：内嵌 SVG 图 + 全部分析表 + 口径出处 | **单文件**，可直接邮件转发 |

- **配色与界面完全一致**（实测=蓝 ×、计算=黑线、差值=红）。色板的唯一出处是
  `ncm/core/palette.py`，GUI 画布与全部导出都从那里取 —— 同一份数据在界面
  与报告里长得一样。
- HTML 报告里的「未测定」项与结果卡口径一致（不显示 0.000 假精度）。
- CLI 等价能力：`--png` / `--svg` / `--points-csv` / `--card-txt` / `--html`。

## 4. 已知局限（如实记录）

1. **峰列表暂不提供 hkl 指标列**。六方 R 晶系（NCM 的 R-3m）的指标约定有坑：
   3-index 下的 R 中心化消光条件 `2h+k+l ≡ 0 (mod 3)` 会把文献常用的
   (105)/(108)/(201) 判为禁戒，而真正贡献这些峰的是同一密排族里的其他成员；
   换成国际四指数 (hkil) 写法禁戒条件又换一套。vendor 的 `compute_peaks`
   按 2θ 合并多重性、不暴露逐 hkl 结构因子，程序内部无法判定某个成员究竟
   是否消光。**只有 2θ 是权威量**，故先只给 2θ / 强度 / 相对强度。
   待「六方 4-index 约化 + 消光条件 + 文献交叉核对」做严谨后，再补指标列
   （计划在 T8.2）。
2. **微观应变默认不精修**（只开尺寸项）：该实样宽化几乎纯尺寸来源，
   均匀应变模型下 ε 无证据（X 触下界）。要开应变项需同时接受「X 与 Y
   强相关、可能落入更差局部极小」的风险（T6.4d 有实测记录）。
3. 导出菜单（PNG / CSV / HTML）已建好但**禁用**，T7.1 实现。
4. 启动图与图标资源尚未落盘（T7.2），当前启动无 splash。
5. **第二相槽位**尚未接入 GUI 界面：核心层 `ncm.core.multiphase` 的
   Hill–Howard 定量已可用（T5.3），GUI 的槽位编辑留给 T7.1/T7.2。
6. GSAS-II 交叉验证仍为 **BLOCKED**（官方渠道全不可用，见
   `docs/GSAS2_STATUS.md`）。
